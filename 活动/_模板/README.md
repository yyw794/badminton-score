# 活动目录说明

每周活动一个独立目录：`活动/YYYY-MM-DD/`。

## 一周目录长什么样

| 文件 | 谁维护 | 说明 |
|---|---|---|
| `01_微信接龙.txt` | 你 | 报名名单，直接贴微信接龙 |
| `02_排阵需求.txt` | 你/大模型 | 本周排阵需求（场地、人数、单打、混双、搭档限制等） |
| `03_排阵输出.xlsx` | 引擎生成 | 对阵表 + 签到表 + 球员统计 + 按人 sheet；默认选中前两页，双面打印一张纸 |
| `04_赛后分析.md` | 大模型生成 | 赛后分析报告 |
| `排阵配置.json` | 大模型/`sync_roster.py` 生成 | 引擎读的机器配置，平时不用改 |
| `排阵输出.json` | 引擎生成 | 对阵的 JSON 版本，便于复查 |
| `比分/` | 你/大模型 | 比分图、`match_data.json`、OCR 输出 |

## 新建一周

```bash
cp -r 活动/_模板 活动/2026-11-09
# 改 01_微信接龙.txt 和 02_排阵需求.txt
.venv/bin/python 排阵系统/sync_roster.py 2026-11-09
.venv/bin/python 排阵系统/weekly.py
.venv/bin/python 排阵系统/solve_lineup.py
.venv/bin/python 排阵系统/export_lineup.py
```

`排阵配置模板.json` 是引擎配置骨架，一般由 `sync_roster.py` 生成/大模型改写，平时不用手填。

## 文件名为什么带序号

`01_` ~ `04_` 让每周目录按「人看/大模型看/打出来/赛后复盘」的顺序排列，打开文件夹一眼就知道先看哪个。

## 打印

打开 `03_排阵输出.xlsx`，默认已选中「对阵表」+「签到表」两个 tab：

1. 打印 → 选“打印活动工作表”
2. 双面打印（长边翻页）
3. 正面是对阵表，反面是签到表；活动时每人签名后交组织人存档

如果部门列有空缺，补 `排阵系统/player_departments.json` 后重新导出即可。

## 历史周

历史周（2026-04 起）已经按同样结构归档。早期没有排阵 Excel 的周，只有 `比分/`；`01_微信接龙.txt` 是按当周出场名单或配置整理的，标注了来源。
