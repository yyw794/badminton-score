# 🏸 平安科技羽毛球队 · 活动与排阵系统

每周一次活动，**一周一个独立目录**。代码与数据分开：`排阵系统/` 放排阵引擎，`比分分析/` 放赛后统计脚本，`活动/<date>/` 只放当周数据。

## 📁 目录结构

```
.
├── 活动/                         # 每周活动（一周一目录）
│   ├── 2026-11-02/
│   │   ├── 01_微信接龙.txt       # 报名名单（你维护）
│   │   ├── 02_排阵需求.txt       # 本周排阵需求（给大模型看）
│   │   ├── 03_排阵输出.xlsx      # 对阵表 + 签到表（默认双面打印一张纸）
│   │   ├── 04_赛后分析.md        # 赛后大模型分析输出
│   │   ├── 排阵配置.json         # 引擎读的机器配置（由需求生成）
│   │   ├── 排阵输出.json         # 引擎生成的对阵 JSON
│   │   └── 比分/                 # 原始比分图 / match_data.json / OCR 输出
│   ├── _模板/                    # 新建一周时复制这里的模板
│   └── 2026-.../                 # 历史各周
├── 排阵系统/                     # 排阵引擎（代码，不随周变）
│   ├── weekly.py                 # 读取 活动/<date>/排阵配置.json
│   ├── solve_lineup.py           # 回溯求解器
│   ├── export_lineup.py          # 硬校验 + Excel 导出（含签到表）
│   ├── sync_roster.py            # 接龙 → 排阵配置
│   ├── paths.py                  # 统一路径
│   ├── excel_exporter.py         # 共享球员名单
│   └── 球队名单.json             # 权威名单（正式/试训/外援 + 部门）
├── 比分分析/                     # 赛后统计/OCR/排名脚本
│   ├── calculate_stats.py
│   ├── paddleocr_vl.py
│   ├── bt/                       # 全局 BT 实力数据
│   └── history/                  # 更早的历史比分
├── 工会杯/                       # 工会杯专项资料
├── 物料需求/                     # 活动物料表
└── README.md
```

## 🚀 每周流程

### 1. 建本周目录

复制 `活动/_模板/` 为 `活动/2026-11-02/`，然后：

- 填 `01_微信接龙.txt`（报名名单）
- 填 `02_排阵需求.txt`（本周特殊要求：场地、人数、单打、混双、搭档限制等）

### 2. 生成排阵

```bash
# 可选：按接龙 + 上周配置生成 排阵配置.json
.venv/bin/python 排阵系统/sync_roster.py 2026-11-02

# 三步：自检 → 求解 → 校验并导出 Excel
.venv/bin/python 排阵系统/weekly.py
.venv/bin/python 排阵系统/solve_lineup.py
.venv/bin/python 排阵系统/export_lineup.py
```

产物：

- `活动/2026-11-02/排阵输出.json`
- `活动/2026-11-02/03_排阵输出.xlsx`（对阵表 + 签到表 + 球员统计 + 按人 sheet）

**打印**：Excel 默认已选中「对阵表」+「签到表」两个 tab，选择“打印活动工作表”并双面打印，就是一张纸：正面对阵、反面签到（现场每人签名后交组织人存档）。

### 3. 赛后

- 比分图 / `match_data.json` 放到 `活动/2026-11-02/比分/`
- 大模型分析结果写到 `活动/2026-11-02/04_赛后分析.md`

```bash
# 例：统计本周
.venv/bin/python 比分分析/calculate_stats.py 活动/2026-11-02/比分/match_data.json
```

## 🧠 排阵规则（简版）

- **能量 = 单打×2 + 双打×1**，能量均衡是最高优先。
- 每人能量目标 = 总能量 ÷ 人数，极差压到结构数学下限。
- 女生体能优先保护；单打 +2 是拉大差距的最大来源。
- 无外援 PK 外援；混双每场至多 1 名外援男。
- 固定搭档、合练对、同队上限、保底场次都在 `排阵配置.json` 里配置。

详细算法见 `排阵系统/求解器算法设计.md`，每周需求模板见 `活动/_模板/02_排阵需求.txt`。
